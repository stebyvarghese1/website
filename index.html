Common Questions

ThreatLens runs alongside Windows Defender, not as a replacement. Where Defender silently blocks with no context, ThreatLens gives you full process lineage, hardware telemetry, explainability AI, and the "Why?" engine — turning your endpoint into a transparent security lab.
Absolutely not. ThreatLens is 100% airgapped. Zero cloud connections, zero accounts, zero file metadata transmission. All analysis including the CyberNLP model inference runs locally and is stored only in your on-disk threatlens.db SQLite database.
Shannon Entropy measures byte-distribution randomness on a scale of 0–8. Normal compiled binaries score ~4.5–6.8. Ransomware, packers, and crypters encrypt their payload bytes, which spike the entropy above 7.4. ThreatLens flags these instantly before execution.
When ThreatLens quarantines a file, it applies a reversible XOR transformation that scrambles the PE header's MZ signature, making the binary mathematically inert — Windows cannot execute it. The transformation is fully reversible if the file turns out to be a false positive, with zero byte loss.
Every suspicious event is parsed through a structured 5-point grammar: (1) What happened, (2) Who did it — process name and PID, (3) Where on disk, (4) Why it matters to your security, and (5) the recommended action. This empowers both security professionals and everyday users to make confident, informed decisions.
