Everything You Need to Know

ThreatLens is designed to run harmoniously alongside Windows Defender or existing antivirus. While traditional antivirus focuses solely on silent signature blocking, ThreatLens provides endpoint observability, parent-child process lineage, hardware telemetry, and explainable AI so you understand every action taking place on your system.

No. ThreatLens is 100% offline and airgap-compatible. It has zero cloud telemetry, zero remote database connections, and does not require an account. All analysis, CyberNLP natural language inference, and SQLite WAL events are stored strictly on your local machine in data/threatlens.db.

Shannon Entropy measures the randomness of bytes in a file on a scale of 0 to 8. Normal compiled software typically has an entropy score between 4.5 and 6.8. Ransomware and packed trojans use heavy encryption or obfuscation, causing the entropy to spike above 7.4. ThreatLens flags high-entropy files instantly before they execute.

When an executable is quarantined, ThreatLens applies a reversible XOR byte transformation that scrambles the file headers (like the Windows PE MZ signature). This makes the file completely inert—even if a user double-clicks it, Windows cannot execute it. However, if it's a false positive, it can be safely restored with zero data corruption.

Instead of cryptic error codes, ThreatLens parses every suspicious action through a 5-point linguistic template: 1. What happened? 2. Who did it? 3. Where on disk? 4. Why does it matter? and 5. Recommended Action. This empowers both cybersecurity pros and everyday users to make informed decisions.
